# SISTEMA DE CADASTRO DE PRODUTOS 

Este projeto implementa um sistema de cadastro de produtos com funcionalidades de criptografia e descriptografia das descrições dos produtos, utilizando Python e um banco de dados Oracle. O sistema permite ao usuário cadastrar, alterar, excluir e visualizar produtos já cadastrados.
